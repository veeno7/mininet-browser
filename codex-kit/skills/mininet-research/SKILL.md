# Research in MiniNet

1. `navigate` (or `open_tab`) with the search words as the url — MiniNet searches Google.
2. Open 2–4 good sources (official sites first). Use `read_text` with `find:"<keyword>"` to pull the exact lines.
3. Every number or name you report must be copied from a page you read in this task — never from memory. Give the source page for each.
4. If sources disagree or you cannot find it, say so.
5. For several topics at once, open one tab per topic and work them in parallel.

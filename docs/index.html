Questions

Is it safe to let an AI use my browser?

You approve each AI before it acts (or choose “Always allow” for ones you trust). You can see everything it does and press Stop AI any time. AI tools can’t touch the browser’s own code, your files, or local pages.

Which AI do I need?

Any. Connect Claude, ChatGPT, Gemini, Cursor or Codex — or use the built-in Orbit assistant with a free local model through Ollama.

What is MiniNet?

MiniNet Chat is a tiny local social feed and chat rooms (Chirp, Talk, People) built into the browser — a safe place to try AI agents before letting them loose on the real web.

Windows says “unknown publisher”.

That’s normal for new apps that aren’t code-signed yet. Click More info → Run anyway. A signed installer is on the roadmap.
